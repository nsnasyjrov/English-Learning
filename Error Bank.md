# Error Bank

Цель файла — хранить только повторяющиеся ошибки, которые реально мешают строить фразы автоматически.

Статусы:
- **ACTIVE** — ошибка повторяется и требует целевой практики.
- **WATCH** — в целом исправлена, но иногда возвращается.
- **CLOSED** — отдельные упражнения больше не нужны; проверять только фоном.

---

## ACTIVE

### 1. Present Simple: he / she / it + `-s`

**Проблема:** в длинных фразах, особенно после `if / when / before`, окончание `-s` иногда теряется или глагол случайно уходит в Past Simple.

**Неправильно:**
- `If the architect approve the changes...`
- `If the administrator give Mark access...`
- `If Mark found the error, he will...`
- `If the manager approved the task today, we will...`

**Правильно:**
- `If the architect approves the changes, we will start testing.`
- `When the administrator gives Mark access, he will start working.`
- `If Mark finds the error, he will report it.`
- `If the manager approves the task today, we will start tomorrow.`

**Механика:**
- `Mark / the manager / the client / he / she / it + V-s`
- `doesn't + V1`
- с `to be`: `is / isn't`, не `doesn't be`

**Мини-формула:**
`If Mark finds... → he will...`

**Последний повтор:** 23.08.2026  
**Статус:** ACTIVE

---

### 2. Future time clauses: `if / when / before + Present Simple`

**Проблема:** при разговоре о будущем после `if / when / before` иногда появляется Past Simple или неправильная форма.

**Неправильно:**
- `If the access came today, I will start...`
- `If the manager approved the task today, we will start...`

**Правильно:**
- `If I get access today, I'll start working tonight.`
- `When the architect approves the changes, we'll start testing.`
- `Before we launch the feature, we need to test it.`

**Правило:**
В реальном условии про будущее:

`if / when / before + Present Simple → will / going to / can / need to ...`

**Не использовать `will` после `if / when` в таких предложениях.**

**Последний повтор:** 23.08.2026  
**Статус:** ACTIVE

---

### 3. `suggest + V-ing`

**Проблема:** периодически возвращается `suggest + to + V1` или `suggest + V1`.

**Неправильно:**
- `suggested to checking`
- `suggested to discussing`
- `suggests postpone the meeting`

**Правильно:**
- `suggest checking`
- `suggest discussing`
- `suggest postponing the meeting`

**Примеры:**
- `The architect suggested checking the code again.`
- `Sara usually suggests discussing these problems with the architect.`
- `We will suggest postponing the release.`

**Последний повтор:** 23.08.2026  
**Статус:** ACTIVE

---

### 4. Access patterns

#### `give someone access to something`

**Неправильно:**
- `give access for me`
- `give access to the database to the developer`
- `give Mark the access`

**Правильно:**
- `give me access`
- `give the developer access to the database`
- `The administrator gave Mark access.`

#### `get access to something`

**Неправильно:**
- `get an access`
- `the access came`

**Правильно:**
- `get access to the server`
- `If I get access today, I'll start working.`

**Важно:** `access` обычно неисчисляемое → без `a/an`.

**Последний повтор:** 23.08.2026  
**Статус:** ACTIVE

---

### 5. Articles: `a / an / the`

**Проблема:** артикли часто теряются в длинных рабочих фразах.

**Типичные случаи:**

`a/an` — один новый, ещё не определённый объект:
- `a task`
- `a meeting`
- `an email`
- `a letter`
- `a serious problem`

`the` — конкретный объект, понятный из контекста:
- `the architect`
- `the manager`
- `the database`
- `the server`
- `the changes`
- `the release`
- `the task`

Без артикля:
- `access`
- `information`
- `work`
- `this week`
- `tomorrow morning`

**Примеры ошибок:**
- `send him letter` → `send him a letter`
- `with architect` → `with the architect`
- `check changes` → `check the changes` (если речь о конкретных изменениях)
- `an access` → `access`

**Статус:** ACTIVE

---

### 6. `will + V1`

**Проблема:** после `will` иногда появляется Past Simple или вообще пропадает основной глагол.

**Неправильно:**
- `I will wrote him tomorrow.`
- `we will tomorrow`

**Правильно:**
- `I will write to him tomorrow.`
- `We will do it tomorrow.`

**Формула:**
`will / won't + V1`

**Примеры:**
- `will write`
- `will check`
- `will start`
- `won't release`

**Статус:** ACTIVE

---

### 7. `ask someone to + V1`

**Проблема:** иногда после `to` появляется `-ing` или `to` пропускается.

**Неправильно:**
- `ask the developer to checking it`
- `ask the administrator give him access`

**Правильно:**
- `ask the developer to check it`
- `ask the administrator to give him access`
- `ask the project manager to postpone the launch`

**Статус:** ACTIVE

## WATCH

### 8. `wait for`

**Правильно:**
- `wait for someone`
- `wait for something`
- `wait for someone to do something`

**Примеры:**
- `I'm waiting for the administrator to reply.`
- `The manager is waiting for his reply.`

**Не:** `wait something`

**Статус:** WATCH

---

### 9. `be related to`

**Правильно:**
- `The problem is related to the server settings.`
- `My task was related to duplicate documents.`

**Не:**
- `is relate`
- `related with`

**Статус:** WATCH

---

### 10. `discuss something with someone`

**Правильно:**
- `discuss the problem with the architect`
- `discuss it with the manager`

**Не:** `discuss about`

**Статус:** WATCH

---

### 11. Past Simple core

**Формулы:**
- `V2` в утверждении
- `didn't + V1`
- `Did + subject + V1?`
- `was / were` для `to be`

**Нерегулярные формы, которые уже встречались:**
- `give → gave`
- `get → got`
- `find → found`
- `send → sent`
- `go → went`
- `write → wrote`
- `have → had`
- `do → did`
- `make → made`
- `take → took`
- `see → saw`
- `buy → bought`

**Последняя свежая ошибка:** `gived` → `gave`

**Статус:** WATCH

---

### 12. `finish + V-ing`

**Правильно:**
- `finish checking`
- `finish testing`
- `finish working`

**Не:** `finish the checking` в обычной речи.

**Статус:** WATCH

## CLOSED / BACKGROUND

### `didn't + V1`
Пример: `We didn't discuss it.`

### Past Simple questions
Пример: `Did you come to the meeting?`

### `reply to someone`
Пример: `The customer replied to the manager.`

### `work on something`
Пример: `I'm working on the task.`

Отдельно не тренировать. Проверять только в свободной речи и письме.

# Time System

## `will`

Использовать для:
- спонтанного решения;
- обещания / предложения помощи;
- прогноза на основе мнения.

Примеры:
- `I'll answer it.`
- `Don't worry. I'll help you.`
- `I think the task will be difficult.`

## `be going to`

Использовать для:
- плана, принятого заранее;
- прогноза по наблюдаемым признакам.

Примеры:
- `I'm going to check the documentation tonight.`
- `Look at those errors. The system is going to crash.`

**Формула:**
- `I'm going to + V1`
- `He is going to + V1`
- `They are going to + V1`

# Review protocol

При следующих занятиях:

1. Не делать отдельный большой тест по всему Error Bank.
2. Брать 2–3 ACTIVE ошибки за занятие.
3. Проверять их в новых контекстах.
4. После 4–5 чистых употреблений без подсказки → перевести в WATCH.
5. Если ошибка возвращается в свободной речи → снова ACTIVE.
6. CLOSED-пункты не дриллить специально.
