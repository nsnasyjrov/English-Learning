## Блок 2. Сделай отрицание и вопрос

Для каждого утверждения напиши отрицание и вопрос.

Пример:

```
The developer sent the report.

Negative: The developer didn't send the report.
Question: Did the developer send the report?
```

1. `The administrator found the problem.`
   Did the administrator find the problem? // He/She/It = Did + inf
   The administrator didn't find the problem
2. `The task was difficult.`
   Was the task diffulcult?
   The task wasn't difficult
3. `We had access to the database.`
   Were we have access to the database?
   We weren't have access to the database
4. `The manager approved the changes.`
   Did the manager approved the changes?
   The managaer didn't approve the changes.
5. `The developers were at the meeting.`
   Were the developers at the meeting?
   The developers weren't at the meeting
6. `The system created a new document.`
   Did the system create a new document?
   The system didn't create a new document.
