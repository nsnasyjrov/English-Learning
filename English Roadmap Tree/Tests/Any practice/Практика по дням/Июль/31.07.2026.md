## Часть 3. Отрицания

>Сделай предложения отрицательными.

1. I work on weekends. 
   I don't work on weekends.
2. My team uses Symfony.
   My team doesn't use Symfony.
3. Alex has access to the server.
   Alex doesn't have access to the server.
4. The application sends notifications.
   The application doesn't send notifications.
5. We have a meeting every morning.
   We doesn't have a meeting every morning.
6. Maria is responsible for the backend.
   Maria is not responsible for the backend.
7. The developers are available after 6 p.m.
   The developers aren't available after 6 p.m.
8. This code looks reliable.
   This code doesn't look reliable.
